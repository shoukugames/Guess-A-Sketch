# Reporting a Bug in Guess-A-Sketch

Thanks for helping make Guess-A-Sketch better! If something doesn't work right,
please send a bug report by either:

- **Email:** info@shoukugames.org (subject: `Guess-A-Sketch bug: <short summary>`)
- **GitHub:** open an issue at https://github.com/shoukugames/Guess-A-Sketch/issues

## Before you report

1. Check you're on the latest version. The version number is shown at the bottom-left of
   the title screen and on the **Credits** screen (for example `v0.1.0`).
2. Try restarting the game and see if the problem happens again.

## What to include

Copy this template and fill in what you can:

```
Game version:        (e.g. v0.1.0, from the title screen or Credits)
Operating system:    (e.g. Windows 11, Ubuntu 24.04, Debian 12)
Installed from:      (.deb package / Windows .exe / source)

What happened:
(Describe the problem.)

What I expected to happen:

Steps to reproduce:
1.
2.
3.

Screen / level where it happened:
(e.g. Title, Play - Level 4 Medium, For Parents, Credits, Game Over)

Word on screen (if any):

How often does it happen?   (every time / sometimes / once)

Screenshot or video:        (attach if possible)
```

## Helpful extra information

- **Progress file:** if the problem involves the **For Parents** screen or saved progress,
  please attach your progress file:
  - Linux: `~/.local/share/guess-a-sketch/progress.json`
  - Windows: `%APPDATA%\GuessASketch\progress.json`
- **Error output (Linux):** run `guess-a-sketch` from a terminal and copy any error text
  it prints.
- **Sound problems:** say whether other apps play sound, and whether the in-game mute button
  (bottom-right speaker, or `F1`) is turned on.
- **Display problems:** say your screen resolution and whether the game was windowed,
  resized, or fullscreen (`F11`).

Please don't include personal information (full names, addresses, passwords) in reports.
